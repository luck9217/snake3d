# Snake3D - Survivor Multiplayer

A fast-paced local multiplayer 3D snake game built with Three.js.

## Live Demo

Play here: https://luck9217.github.io/snake3d/

## Game Overview

- Two-player cooperative snake gameplay on the same keyboard.
- A moving dragon enemy patrols the map.
- Eating apples increases score and gradually increases speed.
- Any collision ends the run.

## Controls

- Player 1 (cyan): Arrow keys
- Player 2 (red): W A S D
- Reset: Space or Reset button

## Rules

- Eat apples to score points.
- Avoid walls.
- Avoid hitting your own snake.
- Avoid hitting the other snake.
- Avoid the dragon.

## UI

- Score counter
- Dragon steps counter
- Match timer
- Neon instruction panel

## Tech

- HTML
- CSS
- JavaScript (ES modules)
- Three.js

## Run Locally

Open `index.html` in a modern browser.

For best results, use a local static server.
